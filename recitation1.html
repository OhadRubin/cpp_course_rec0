Naming:

Names should be descriptive; avoid abbreviation. Here’s a suggestion for a naming system:

  • Variables and data members: snake_case
  • Function and member functions: camelCase
  • Classes/Structs: PascalCase
  • Never use: Capital_Snake_Case ❌
  • Just be consistent!
  • Google C++ Style Guide

This is a suggestion from what my team used. There are a lot of minutiae one can consider, such as namespaces, statics, etc. Another system one can consider is https://en.wikipedia.org/wiki/Hungarian_notation. Consistency really is the only requirement.

Parameters vs. Arguments

#include <iostream>

void fooByValue(int num) {
    std::cout << num << std::endl;
    num = num + 10;
}

void fooByReference(int& num) {
    std::cout << num << std::endl;
    num = num + 10;
}

void fooByPointer(int* num) {
    std::cout << *num << std::endl;
    *num = *num + 10;
}

int main() {
    int number = 10;
    fooByValue(number);
    fooByReference(number);
    fooByPointer(&number); 
    std::cout << number << std::endl;
}

Parameters define what a function expects.

Arguments are what you actually provide.

const * | * const | const * const

#include <iostream>

// 1. const <type>* ptr
// Pointer can point elsewhere, but the pointed data can't be changed.
void exampleConstData(const int* ptr) {
    // *ptr = 5; // Error! Cannot modify the data
    ptr++;        // Allowed, pointer can move
    std::cout << "Value pointed to: " << *ptr << std::endl;
}

// 2. <type>* const ptr
// Pointer is constant (cannot point elsewhere), but pointed data can change.
void exampleConstPointer(int* const ptr) {
    *ptr = 10;   // Allowed, data can be modified
    // ptr++;    // Error! Cannot modify the pointer itself
    std::cout << "Modified data: " << *ptr << std::endl;
}

// 3. const <type>* const ptr
// Neither pointer nor pointed data can be modified.
void exampleConstDataConstPointer(const int* const ptr) {
    // *ptr = 15; // Error! Cannot modify the data
    // ptr++;     // Error! Cannot modify the pointer
    std::cout << "Constant value and pointer: " << *ptr << std::endl;
}

int main() {
    int arr[] = {1, 2, 3};

    exampleConstData(arr);              // Pointer moves, data constant
    exampleConstPointer(arr);           // Data changes, pointer constant
    exampleConstDataConstPointer(arr);  // Both pointer and data constant

    return 0;
}
